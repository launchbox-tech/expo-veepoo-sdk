# 1.3.0

## Breaking: flat-legacy SDK surface removed

The ~80 flat-legacy delegation methods on `VeepooSDK` (e.g. `sdk.readBattery()`, `sdk.startScan()`, `sdk.connect(deviceId)`, `sdk.setAlarm(alarm)`, …) have been **removed**. Every host-app call site must use the namespaced surface, which has been the only documented API in `README.md` and the only API used by `example/` for several releases. See **ADR 0005** for the architectural reason: the flat-legacy block was a hand-maintained shadow of the typed capability properties on `VeepooSDK`, which already provide composition by construction.

## Migration

Mechanical: prefix each flat call with its capability namespace. The mapping is one-to-one — no signature or behaviour changes.

## Unchanged

The lifecycle and event API on `VeepooSDK` stays as-is: `init()`, `destroy()`, `setLogEnabled()`, `isLogEnabled()`, `setLogger()`, `isScanningActive()`, `isSDKInitialized()`, `getConnectedDeviceId()`, `on()`, `off()`, `once()`, `removeAllListeners()`. The 36 capability properties (`sdk.battery`, `sdk.session`, …) are unchanged. The React provider (`VeepooSDKProvider`, `useVeepooSDK`, `useSDKState`, convenience hooks) is unchanged.
